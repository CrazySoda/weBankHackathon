Appendix · Jury Q&A Defense

Technical Jury Defense & FAQ

Direct answers to the most critical technical questions.

Q1: What if the LLM hallucinates an invoice amount?

The LLM extracts fields into strict Pydantic schemas with bounding coordinates. The verification node deterministically cross-checks extracted numbers directly against raw PDF text. If extraction confidence is low, the system fails closed to escalate.

Q2: Why integer math instead of LLM calculation?

LLMs are probabilistic token predictors, not calculators. Floating-point numbers cause rounding drift. Our app/calc/ engine operates in integer minor units (cents) with 100% branch test coverage, guaranteeing absolute mathematical exactness.

Q3: How do you prevent replay attacks on payouts?

Two independent controls: the Ed25519 signature binds the canonical deal hash (including deal ID and timestamp), and the execute node acquires a single-use Redis distributed lock via SETNX deal:{id}:payout before touching the sandbox API.

Q4: Does ClearTrade comply with Chinese AI regulations?

Yes. ClearTrade natively supports DeepSeek V3 and Alibaba Qwen 2.5 via LiteLLM gateway, ensuring data residency within mainland China and compliance with domestic cross-border financial data sovereignty laws.
